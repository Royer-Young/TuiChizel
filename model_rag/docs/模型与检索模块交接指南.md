# 模型与检索模块交接指南

为保证大模型和 RAG 检索顺利运行，请务必按以下步骤操作：

## 1. 安装依赖
如果你还没安装依赖，请在项目根目录运行：
`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

## 2. 配置 API Key（必做）
在项目根目录新建一个 `.env` 文件，里面填入一行（千万别带引号或空格）：
`DEEPSEEK_API_KEY=sk-你的真实Key`

## 3. 准备向量模型（重点避坑！）
`rag.py` 已改为自动查找本地模型，不再需要手改源码。在项目根目录运行：

```bash
python model_rag/setup_model.py
```

脚本会把 bge-small-zh-v1.5 下载到 `models/` 下，后端自动识别。
如果模型放在别处，在 `.env` 里加一行 `BGE_MODEL_PATH=你的模型目录` 即可。

模型加载失败时后端不会退出：`/api/health` 的 `rag.model_error` 会给出原因，
评价接口会退回「无知识库依据」模式并在响应里带 `warning`。

## 4. 联调测试
在根目录运行 `python model_rag/rag.py`，如果打印出 `✅ 成功索引 45 条知识库数据！`，说明你的环境完全配置成功。
（后端在 `backend/main.py` 中通过 `from model_rag.rag import search` 调用）
